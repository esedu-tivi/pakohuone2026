Muuntakaa binääriluku kymmenjärjestelmään — se on WiFi-salasana.
Binääriluku muunnetaan kymmenjärjestelmään kertomalla jokainen bitti kahden potenssilla sen paikan mukaan (oikealta alkaen, paikka 0):
2⁰ = 12¹ = 22² = 42³ = 8
2⁴ = 162⁵ = 322⁶ = 642⁷ = 128

Esimerkki: 1010 = 1×8 + 0×4 + 1×2 + 0×1 = 10
